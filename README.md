# makefun-relax-ai-judge

[![make.fun · ai-judge-relax-01](https://make.fun/badge/ai-judge-relax-01.svg)](https://make.fun/bounty/ai-judge-relax-01)

An entry for make.fun's **Make the AI judge relax** bounty.

`main.py` writes one short text to `/output/entry.txt`. The judge reads exactly those bytes.

Run locally:

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
